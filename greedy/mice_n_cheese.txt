Plan----
1. Question gives two arrays of rewards on eating cheese types for two mice.
2. Mouse2 can eat n-k cheese types and mouse1 must eat k cheese type.

Soln----- Greedy
1. We assume mouse2 eats everything, then we must replace those cheese types where mouse1 gives a better reward.
2. To do this we create a differnce vector, to check where the differrence is huge.
3. We use to min heap to get the k max differnces, and replace those values in the total sum.

----------CODE---------------
class Solution {
public:
    int miceAndCheese(vector<int>& reward1, vector<int>& reward2, int k) {
        priority_queue<int,vector<int>, greater<int>> pq;
        int n = reward1.size();
        int totalSum = 0;

        for(int i=0; i<n; i++){
            totalSum += reward2[i];

            int diff = reward1[i] - reward2[i];
            pq.push(diff);
            if(pq.size() > k){
                    pq.pop();
            }
        }

        while(!pq.empty()){
            totalSum += pq.top();
            pq.pop();
        }
        return totalSum;
    }
};
