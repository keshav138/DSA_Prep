These are the graph representations and when and where to use them.


Here is how you handle the three representations in **C++**.

---

## 1. Adjacency Matrix

In C++, this is usually a `vector<vector<int>>` or a static 2D array if the constraints are small ($N \le 500$).

```cpp
#include <iostream>
#include <vector>

void traverseMatrix(int n, const std::vector<std::vector<int>>& matrix) {
    int u = 0; // Starting at node 0
    for (int v = 0; v < n; v++) {
        // If matrix[u][v] is 1 (or weight > 0), an edge exists
        if (matrix[u][v] != 0) {
            std::cout << "Neighbor found: " << v << std::endl;
        }
    }
}

```

---

## 2. Adjacency List

This is the gold standard for C++ competitive programming. Use a `vector<int> adj[N]` for fixed sizes or `vector<vector<int>>` for dynamic sizing.

```cpp
#include <iostream>
#include <vector>

void traverseList(int u, const std::vector<std::vector<int>>& adj) {
    // You loop directly over the neighbors of 'u'
    // This is O(degree of u), much faster than O(V) for matrices
    for (int neighbor : adj[u]) {
        std::cout << "Connected to: " << neighbor << std::endl;
    }
}

```

---

## 3. Edge List (The "Conversion" Step)

Many platforms (like LeetCode) provide input as `vector<vector<int>>& edges`. To avoid a Time Limit Exceeded (TLE) error, convert this to an adjacency list before starting your BFS/DFS.

```cpp
#include <vector>

std::vector<std::vector<int>> buildAdjList(int n, std::vector<std::vector<int>>& edges) {
    std::vector<std::vector<int>> adj(n);
    for (auto& edge : edges) {
        int u = edge[0];
        int v = edge[1];
        
        adj[u].push_back(v);
        adj[v].push_back(u); // Remove this line if the graph is directed
    }
    return adj;
}

```

## Summary of the "Mental Switch"

| If the input is... | Your Loop looks like... | Efficiency |
| --- | --- | --- |
| **Matrix** | `for (int v=0; v<n; v++) if (mat[u][v])` | $O(V)$ per node |
| **List** | `for (int v : adj[u])` | $O(1)$ per edge |
| **Edge List** | **STOP.** Convert to Adjacency List first. | $O(E)$ total |

