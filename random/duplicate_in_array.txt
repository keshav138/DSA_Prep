
Basically need to find duplicate in an array in linear time, where values are of the range [1-n]
Need to implement a fast and slow pointer approach, every value acts like its next index, so like a linked list with a loop

Using a fast and slow pointer, they intersect but they dont intersect at the start of the loop(duplicate element), more so at some place 
in the cycle
For this we keep the slow pointer as it is, and create another / take the fast pointer at the start of the array again.
Move both the new and slow pointer ahead one by one till they meet. Reason -> distance of new pointer to duplicate == distance of slow poitner 
inside cycle to the duplicate

class Solution {
public:
    int findDuplicate(vector<int>& nums) {
        int slow = nums[0];
        int fast = nums[0];

        while(true){
            slow = nums[slow];
            fast = nums[nums[fast]];
            if(slow == fast) break;
        }

        int slow2 = 0;

        while(true){
            slow = nums[slow];
            slow2 = nums[slow2];
            if(slow == slow2) break;
        }
        return slow;

    }
};
