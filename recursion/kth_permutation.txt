PLAN--------------------

Need to find the kth permutation for a given n, recursion is not the optimal solution, where we calculate all the possible permutations
and then sort the answer list.
We solve by using maths: 

[1,2,3,4], given, has 24 permutations, and if we're to find the 17th permutation, we seggregate the output, to get to the answer:

index - based on the above list indexing.

1+[2,3,4] -> n=3, 6 permutation index =0
2+[1,3,4] -> n=3, 6 permutation index =1
3+[1,2,4] -> n=3, 6 permutation index =2
4+[1,2,3] -> n=3, 6 permutation index =3

so we're using 0th based permutations so we're finding in which block does the 16th permutation lie, which is k/(n-1)!, which here is 16/6 i.e 2
meaning the starting index[2], and number is 3, so we add it to the string and remove it from the vector.

To find the position of the 16th index inside the 2nd block we use k%(n-1)!, which is 16%6 = 4. Therefore for the new iteration we need to find the
4th permutation from [1,2,4].

1+[2,4] -> n=2, 2 permutation, index = 0
2+[1,4] -> n=2, 2 permutation, index = 1
4+[1,2] -> n=2, 2 permutation, index = 2

so we're using 0th based permutations so we're finding in which block does the 4th permutation lie, which is k/(n-1)!, which here is 4/2 i.e 2
meaning the starting index[2], and number is 4, so we add it to the string and remove it from the vector.


To find the position of the 4th index inside the 2nd(based on 0 indexing) block we use k%(n-1)!, which is 4%2 = 0.
 Therefore for the new iteration we need to find the 0th permutation from [1,2].

 1+[2] -> n=1, 1 permutation, index = 0
 2+[1] -> n=1, 1 permutation index = 1

so we're using 0th based permutations so we're finding in which block does the 0th permutation lie, which is k/(n-1)!, which here is 0/1 i.e 0
meaning the starting index[0], and number is 1, so we add it to the string and remove it from the vector.

To find the position of the 0th index inside the 0th(based on 0 indexing) block we use k%(n-1)!, which is 0%0 = 0.
 Therefore for the new iteration we need to find the 0th permutation from [2].

Coming to the last answer i.e 2, leaving us with [3,4,1,2] as the 17th permutation.

-----------------CODE----------------------

--> mind the order of things, first calculate the n-1 th factorial, reduce k to 0 indexing
--> while loop order matters, add to string, erase from vector, check vector size to exit, else reduce and fact. 


class Solution {
public:
    string getPermutation(int n, int k) {
        int fact = 1;
        vector<int> tank;
        for(int i=1; i<n; i++){
            tank.push_back(i);
            fact *= i;
        }
        tank.push_back(n);
        string s = "";
        k -= 1; // to change to 0 based indexing

        while(true){
            s = s + to_string(tank[k/fact]);
            
            tank.erase(tank.begin()+ k/fact);
            if(tank.size()==0) break;

            k = k%fact;
            fact = fact / tank.size();

        }

        return s;
    }
};
