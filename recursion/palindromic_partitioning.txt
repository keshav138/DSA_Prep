Plan
- Core question is to create partitions in string s, such that every substring of the partition is a palindrome.
- Subsequence doesn't work here because subsequence and substring are different, substring are contigious whereas subsequence is non-contigious,
- Subsequence is basically cherry picking , we can pick from anywhere, whereas substring if put back together should make the same string again.

Soln-
- We start at the string, and at every recursion check if partition at every index is possible or not, possibility check of the partition 
is by checking whether the string on the left is a palindrome or not.
- If yes, then we add then substring to the curr_ds, then recurse to the next index, then checking in a looping manner where a partition is possible
from index to n-1.


--> We hold a string(the main), an index, a current structure with substrings, and another data structure that contains all the calculate list of 
substrings

, because the partition to that point is something like  a | a | b | "b", so the last is still a string, only when the pointer goes to the end

void partition(int idx, string s, vector<vector<int>>&answer, vector<int>&current){
    if(idx == s.length()){
        answer.push_back(current);
        return;
    }

    for(int i=idx; i<s.length(); i++){
        if(isPalindrome(idx, i, s)){
            answer.push_back(s.substr(idx, i-idx+1)); // substr in cpp used (index, length to substring)
            partition(idx+1, s, answer, current);
            answer.pop_back();
        }
    }
}

bool isPalindrome(int low, int high, string s){
    while(low < high){
        if(s[low]==s[high]){
            low++;
            high--;
        }
        else return false;
    }
    return true;
}


------------------DP_MEMOIZATION-------------------

-Basically we add memory to the palindrome function

Steps
1. first, we check if we already know if given substring is a palindrome
2. second is a base case check if we didnt know anything about the entire string, the recursion comes here only if its a palindrome, which is
the low and high cross each other, or low == high(meaning on one character), we return 1.
3. first check, into the function, if the end and start characters are the same, we move in
    3.1 then check if we already know whether the inner string is a palindrome, we call the function directly , because it lazily check the very first
    condition if we already know if its a palindrome or not.
4. if the first and last we're not same then its obviously not a palindrome, so we update memo and return memo[low][high].

class Solution {
public:
    vector<vector<string>> partition(string s) {
        vector<vector<string>> answer;
        vector<string> current;
        // maintain a dp nxn array for string s of length n
        vector<vector<int>> memo(s.length(), vector<int>(s.length(), -1));

        partition(0, s, current, answer, memo);
        return answer;
    }

    void partition(int idx, string s, vector<string>&current, vector<vector<string>>&answer, vector<vector<int>>&memo){
        if(idx == s.length()){
            answer.push_back(current);
            return;
        }

        for(int i=idx; i<s.length(); i++){
            if(isPalindrome(idx, i, s, memo)){
                current.push_back(s.substr(idx, i-idx+1));
                partition(i+1, s, current, answer, memo);
                current.pop_back();
            }
        }
    }

    bool isPalindrome(int low, int high, string s, vector<vector<int>>&memo){
        if(memo[low][high] != -1) return memo[low][high];
        if(low >= high) return 1;

        if(s[low]==s[high]){
            memo[low][high] = isPalindrome(low+1, high-1, s, memo);
        }
        else memo[low][high]=0;
        
        return memo[low][high];
    }
};
