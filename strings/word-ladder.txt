You've got a startWord and a endWord, and a list of words, which all differ by 1 character, from an existing word. If the end word is not in the list it is not reachable, so thats the first check.
We're to simply tell how many jumps of successive words with max character difference 1, is it going to take us to get to the endword.
We use the bfs technique here.
We assume every word is a node, and attached to it are words from the list which differ with atmost 1 in char length, our aim to reach to final node which is our endWord.

Since we're to find the shortest path from start to end, we'll be using bfs, since it checks with all nodes at the current level, before moving forward, giving us the shortest path.

We create the set of the list of words for O(1) access, and a queue to maintain our word and our steps.
Once we find a word, we replace every letter of it from [a-z] to check if we have the word in the list. If yes, we've found another node, remove from the set to avoid infinite loop, rest insert the new one into the queue.

 class Solution(object):
    def ladderLength(self, beginWord, endWord, wordList):
        """
        :type beginWord: str
        :type endWord: str
        :type wordList: List[str]
        :rtype: int
        """

        hash = set(wordList)

        if endWord not in hash:
            return 0
        
        queue = deque([(beginWord, 1)])

        while queue:
            current_word, steps = queue.popleft()

            if current_word == endWord:
                return steps
            
            for i in range(len(current_word)):
                for c in "abcdefghijklmnopqrstuvwxyz":
                    new_word = current_word[:i] + c + current_word[i+1:]
                    
                    if new_word in hash:
                        hash.remove(new_word)
                        queue.append((new_word, steps+1))
        return 0
